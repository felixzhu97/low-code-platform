# E3 数据、图表与表单

← [用户故事地图](../User-Story-Map.md)

## 背景

开发者通过数据面板管理数据源与绑定，使用图表展示数据，并用表单构建器快速搭建采集界面。

---

## US-07 数据源与绑定

**As a** 开发者  
**I want** 配置数据源并将字段绑定到组件  
**So that** 页面可以展示动态数据

### 验收标准

1. **Scenario** 管理数据源
   **GIVEN** 用户打开数据相关面板  
   **WHEN** 用户新增或选择数据源  
   **THEN** 该数据源可被后续绑定引用

2. **Scenario** 绑定到组件
   **GIVEN** 已存在数据源与可选中组件  
   **WHEN** 用户为组件配置数据绑定  
   **THEN** 组件按绑定规则展示或更新数据

### 状态

已实现

---

## US-08 图表组件

**As a** 开发者  
**I want** 在画布上使用柱状图、折线图、饼图等图表  
**So that** 我可以可视化展示指标

### 验收标准

1. **Scenario** 添加图表
   **GIVEN** 组件面板包含图表类型  
   **WHEN** 用户将图表放到画布  
   **THEN** 显示默认或绑定数据后的图表

2. **Scenario** 切换图表类型/配置
   **GIVEN** 画布上已有图表实例  
   **WHEN** 用户在属性中调整图表配置  
   **THEN** 图表呈现按配置更新

### 状态

已实现

---

## US-09 表单构建器

**As a** 开发者  
**I want** 用表单构建器组装带校验的表单  
**So that** 我可以快速创建数据收集页面

### 验收标准

1. **Scenario** 组装表单字段
   **GIVEN** 用户打开表单构建能力  
   **WHEN** 用户添加输入字段并配置标签/校验  
   **THEN** 画布或预览中呈现对应表单项

2. **Scenario** 校验规则生效
   **GIVEN** 字段已配置必填或格式校验  
   **WHEN** 用户在预览中提交非法值  
   **THEN** 展示校验反馈且阻止无效提交（按实现）

### 状态

已实现
