# E4 主题与动画

← [用户故事地图](../User-Story-Map.md)

## 背景

设计师通过主题编辑器统一视觉 token，并通过动画编辑器为组件增加动效。

---

## US-10 主题编辑

**As a** 设计师  
**I want** 可视化调整主题色、字体等 token  
**So that** 页面整体风格保持一致且符合品牌

### 验收标准

1. **Scenario** 打开主题编辑器
   **GIVEN** 用户处于编辑器  
   **WHEN** 打开主题编辑入口  
   **THEN** 可编辑主题相关配置项

2. **Scenario** 主题应用到画布
   **GIVEN** 用户修改了主题配置  
   **WHEN** 保存或即时应用  
   **THEN** 画布上受主题影响的组件外观更新

### 状态

已实现

---

## US-11 动画编辑

**As a** 设计师  
**I want** 为选中组件配置动画效果  
**So that** 交互与展示更具表现力

### 验收标准

1. **Scenario** 为组件添加动画
   **GIVEN** 用户已选中画布组件  
   **WHEN** 在动画编辑器中选择或配置动画  
   **THEN** 该组件关联对应动画配置

2. **Scenario** 预览动画
   **GIVEN** 组件已配置动画  
   **WHEN** 用户预览页面或触发动画预览  
   **THEN** 可观察到动画效果

### 状态

已实现
