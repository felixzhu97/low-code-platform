# E1 画布与可视化编辑

← [用户故事地图](../User-Story-Map.md)

## 背景

开发者在中央画布上拖拽放置组件，通过属性面板配置外观与行为，并支持预览与撤销/重做。

---

## US-01 拖拽构建页面

**As a** 开发者  
**I want** 从组件面板拖拽组件到画布  
**So that** 我可以可视化地搭建页面布局

### 验收标准

1. **Scenario** 拖拽放置组件
   **GIVEN** 用户已打开编辑器且组件面板可见  
   **WHEN** 用户将某组件类型拖到画布有效区域并放下  
   **THEN** 画布上出现对应组件实例  
   **AND** 该实例处于可选中状态或可被立即选中

2. **Scenario** 无效放置不破坏画布
   **GIVEN** 用户正在拖拽组件  
   **WHEN** 用户在画布外取消或放置失败  
   **THEN** 画布既有组件结构保持不变

### 状态

已实现

---

## US-02 属性配置

**As a** 开发者  
**I want** 在右侧属性面板编辑选中组件的属性  
**So that** 我可以调整样式、文案与交互而不改代码

### 验收标准

1. **Scenario** 选中后展示属性
   **GIVEN** 画布上至少有一个组件实例  
   **WHEN** 用户点击选中该实例  
   **THEN** 属性面板展示该组件可编辑属性

2. **Scenario** 修改立即反映
   **GIVEN** 用户已选中组件且属性面板已打开  
   **WHEN** 用户修改某一属性值  
   **THEN** 画布上该组件的呈现随之更新

### 状态

已实现

---

## US-03 预览与撤销重做

**As a** 开发者  
**I want** 预览最终效果并撤销/重做误操作  
**So that** 我可以安全地迭代设计

### 验收标准

1. **Scenario** 进入预览模式
   **GIVEN** 画布上已有若干组件  
   **WHEN** 用户切换到预览  
   **THEN** 以接近最终页面的方式展示内容  
   **AND** 编辑拖拽交互不再改变布局（或按产品定义禁用编辑）

2. **Scenario** 撤销与重做
   **GIVEN** 用户刚完成一次会改变画布的操作  
   **WHEN** 用户执行撤销  
   **THEN** 画布恢复到该操作之前的状态  
   **AND** 重做可再次应用该操作

### 状态

已实现
