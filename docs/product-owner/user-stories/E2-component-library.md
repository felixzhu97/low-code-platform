# E2 组件库

← [用户故事地图](../User-Story-Map.md)

## 背景

平台提供内置 UI/布局/图表等组件，并支持自定义组件与层级化的组件树管理。

---

## US-04 内置组件库

**As a** 开发者  
**I want** 从分组的内置组件库中选择常用组件  
**So that** 我无需从零实现基础 UI

### 验收标准

1. **Scenario** 浏览内置组件
   **GIVEN** 用户打开编辑器  
   **WHEN** 查看左侧组件面板  
   **THEN** 可见分类后的内置组件（如按钮、布局、图表等）

2. **Scenario** 使用内置组件
   **GIVEN** 组件面板已展示某内置组件  
   **WHEN** 用户将其放到画布  
   **THEN** 渲染为该类型的默认实例

### 状态

已实现

---

## US-05 自定义组件

**As a** 设计师  
**I want** 创建和管理自定义组件  
**So that** 团队可以复用业务特定 UI

### 验收标准

1. **Scenario** 注册自定义组件
   **GIVEN** 用户具备自定义组件能力入口  
   **WHEN** 用户创建或导入自定义组件定义  
   **THEN** 该组件出现在可选用列表中

2. **Scenario** 复用自定义组件
   **GIVEN** 自定义组件已存在于列表  
   **WHEN** 用户将其放到画布  
   **THEN** 画布出现基于该定义的实例

### 状态

已实现

---

## US-06 组件分组与树

**As a** 开发者  
**I want** 通过组件树查看层级并组织组件  
**So that** 我能快速定位与调整复杂页面结构

### 验收标准

1. **Scenario** 查看组件树
   **GIVEN** 画布上存在嵌套或并列组件  
   **WHEN** 用户打开组件树视图  
   **THEN** 展示与画布一致的层级结构

2. **Scenario** 从树选中组件
   **GIVEN** 组件树已展示  
   **WHEN** 用户点击树中某一节点  
   **THEN** 画布选中对应实例且属性面板同步

### 状态

已实现
