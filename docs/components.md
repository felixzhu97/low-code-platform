# Components

## UI Components

| Component | Description |
|-----------|-------------|
| Button | Primary, Secondary, Ghost, Outline variants |
| Input | Text, Number, Password with validation |
| Select | Single/Multi select dropdown |
| Checkbox | Single or grouped checkboxes |
| Switch | Toggle switch |
| Slider | Range slider |

## Layout Components

| Component | Description |
|-----------|-------------|
| Container | Wrapper with padding and max-width |
| Row | Horizontal flex container |
| Column | Vertical flex container |

## Chart Components

| Component | Description |
|-----------|-------------|
| BarChart | Vertical/horizontal bar charts |
| LineChart | Line charts with markers |
| PieChart | Pie and donut charts |
| AreaChart | Filled area charts |
| RadarChart | Radar/spider charts |
| ScatterChart | Scatter plot diagrams |
| GaugeChart | Circular gauge display |
| TreemapChart | Hierarchical treemap |
| RadialBarChart | Radial bar visualization |

## Form Components

| Component | Description |
|-----------|-------------|
| Form | Form container with validation |
| FormField | Field wrapper with label/error |
| FormItem | Individual form element |

See [C4 Component Diagrams](c4/README.md) for architecture details.
